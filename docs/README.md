# project-docs-protocol — its own docs

The skill runs the protocol it ships. Bootstrap: read `STATUS.md`, then the last 3–5 `CHANGELOG.md` entries, then skim `DECISIONS.md`. Close: CHANGELOG entry first, then rewrite STATUS, then a DECISIONS entry only if a real alternative was rejected. Formats are the ones in `../templates/README.md`.

The audit that produced the current state is private; its population-level findings are in `EVIDENCE.md`, and its ranked recommendations are this repo's roadmap.
